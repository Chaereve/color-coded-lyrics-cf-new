## Phạm vi và độ tin cậy

Quét **tất cả tracked text files**, tên đường dẫn và XML bên trong DOCX; pattern `quiz`, `question[-_ ]bank`, `daily[-_ ]reward(s)`, `daily[-_ ]login`, `checkInCalendar`; thêm shared dependencies bằng đọc call sites. Bảng bên dưới là file-level inventory, bảng object nằm ở [02-database.md](02-database.md). Line anchors là base commit, không phải deployed SHA. Không suy ra production usage từ tên migration/baseline.

**Không thấy trong source**: route Question Bank/admin QA riêng, quiz API Cloudflare/Edge function, quiz view/materialized view, quiz cron, quiz-specific environment variable; admin tabs là pending/active/expired/orders/done/media/comments. QA bank là pipeline CSV/tooling/manual SQL, không phải trang admin đã triển khai. DB Dashboard functions/jobs/manual views ngoài repo **chưa xác minh**.

**Giữ nguyên**: Daily Spin, activity streak, achievements, purchased votes, season rewards, vote gate, backup cron, R2/D1/KV. Achievement catalog dùng activity/longest streak, không có source quiz riêng trong repo. Login claim hiện ghi activity_days nên có liên hệ gián tiếp với achievement; không đổi nó sang login streak hoặc phát lại achievement.
